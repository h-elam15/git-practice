This is a Java project to run a simple webpage and calculate BMI.
In BMIApplication.java run the program.
Give Spring Boot time to load, once you see the logo you are good to advance to the webapage.
Then type localhost:8080 into your browser (I know Chrome works but any should be fine) to see the HTML webpage.
(Spring Boot will say "Tomcat initalized with port 8080 (if you see a diffrent port use that)).
Enter your height in feet and inches and weight in pounds.
When you hit enter you will see your BMI and weight class.
